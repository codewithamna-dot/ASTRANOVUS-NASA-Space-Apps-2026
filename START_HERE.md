# Rewind the Murder — Walkable Edition

Open index.html to play. No installation needed.

WASD: walk. Drag: look. Shift: run. Space: jump. E: inspect nearby. Use the camera button for first/third person. Touch controls are on-screen. Play Training for guided investigation practice.

For GitHub Pages, upload the contents of this folder to your repository and enable Pages from the main branch root. All files, including dist/assets/menu-loop.mp4, must be included. Read README.md for details.
